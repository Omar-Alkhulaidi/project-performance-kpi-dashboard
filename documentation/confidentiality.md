# Confidentiality & Portfolio Usage

## Project Context

This repository documents a Power BI solution developed during my professional work at **SMEPS** for a privet sector department ESPECRP project.

The original project used organizational CRM and operational data containing beneficiary and project information.

---

## Why the Full Project Cannot Be Published

The underlying data is confidential and was not created for public distribution.

The original dataset may contain information such as:

- Beneficiary names
- Gender
- Location information
- Grant information
- Grant status
- Grant amounts
- Training status
- Other project-related operational fields

For this reason, the original data and analytical file are not included in this repository.

---

## Publicly Shared Material

This repository intentionally contains only:

- A dashboard preview screenshot
- A high-level project description
- A description of the analytical methodology
- The technologies used
- A summary of my contribution

The repository does **not** contain:

- CRM exports
- Google Sheets source data
- PBIX files
- Beneficiary records
- Personally identifiable information
- Individual financial records
- Internal project documentation

---

## Portfolio Purpose

This repository is intended to demonstrate the type of analytical work delivered in a professional environment while respecting the confidentiality of the underlying project.

The emphasis is therefore placed on:

- Business problem definition
- KPI design
- Data preparation
- Power BI development
- DAX-based analytics
- Interactive reporting
- Stakeholder-oriented visualization

---

## Data Ownership

The original data remains the property of the organization and/or its authorized data sources.

No ownership of the underlying data is claimed by this repository.

If access to the original project materials is required, it should be obtained through the appropriate organizational channels.
